## backup-payload

# Welcome to the 2027 backup payload team!  

# Competition Objective:  
We need to drop a 3lb (1.36kg), 11in x 9in x 4in (280mm x 230mm x 102mm) object from a height of >=150ft above the ground within a 100ft diameter circle on the ground.  

The object must land intact and cannot free-fall!

# Design Priorities:

1: Reliability and Simplicity - This is the fallback plan and cannot fail!
2: Aerodynamics - We cannot add excessive drag to the airframe.
3: Weight - We are trying to stay under a total airframe weight of 18lb (8.16kg).
4: Power - We cannot draw excessive amounts of power for our system.

# Current Design:

We are going for a design based on a jet fighter drop tank design, with a blunter tip as we are not traveling supersonic.

- Electromagnetic release system (energize to release)
- Parachute retardant mechanism
- Completely unguided
